# Route Prop Graphics Attribution

Generated route scenes use a deliberately small set of object-event graphics.
Imported tiles are complete source-sheet objects reduced to native GBA scale
where necessary and remapped to existing Emerald NPC palettes. The original
source sheets are not shipped in the repository or embedded in the ROM.

## J-Treecko252

The following complete object is taken from J-Treecko252's Gen III rock tiles,
published as free to edit and use with credit:

- `split_rock.png`: [Rock Tiles Ver.01](https://www.deviantart.com/j-treecko252/art/Rock-Tiles-Ver-01-884759152)

The source sheets are pixel-doubled for Pokémon Essentials. The selected
objects were reduced exactly to native GBA scale before palette remapping.

## Ekat's Public Gen 3 Tilesets

The following graphics are adapted from sheets in
[Ekat's Public Gen 3 Tilesets](https://eeveeexpo.com/resources/621/):

- `stump.png`: `Daisy Route.png` — Idilio, Heroalistar, Ekat, Zeo, Zein,
  J-Treecko252, 874521, The Red-Ex, Kyledove, Magiscarf, and Wesley FG.
- `supply_crate.png`: `Cold Storage Interior.png` — Ekat, Vurtax, and
  Heartlessdragoon.
- `mossy_stone.png`, `round_stone.png`, and `stone_pile.png`: `More Ruins
  Tiles.png` — Ekat, Vurtax, and Heartlessdragoon.

Credits are reproduced from the per-sheet `Credits.txt` included with version
4.0 of the public pack.

## TerribleJared

- `occult_altar.png`: [Relic Hunters Mini Pack](https://www.eeveeexpo.com/resources/1949/)
  by TerribleJared, published as public and free to use.

The pack is supplied at 2x pixel density; the complete altar object was reduced
exactly to native GBA scale before palette remapping.

## Divergence Originals

The remaining files in this directory are project-specific graphics created
for Pokémon Emerald Rogue: Divergence. The Spirit Stone was designed as the
distinct non-interactive marker for the Forbidden Stone quest.
