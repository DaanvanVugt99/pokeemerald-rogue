# PKMN DIVERGE — Preview

This is a private friend preview of Pokemon Emerald Rogue: Divergence.

## Start playing

1. Open `pokeemerald-divergence-preview.gba` in mGBA 0.10.5 or another
   Game Boy Advance emulator.
2. Choose **New Game**.
3. Complete the onboarding prompts. The Pokédex choice determines the
   Pokémon available in the run and the first partner choices.
4. Save normally through the in-game menus. Keep the emulator save file with
   the ROM if you move the preview to another computer.

Build identifier: `Preview`
ROM source commit: `dc65cec08d5bfc0cd9b5810e25822f3429118cb2`

## Feedback

For this private preview, report crashes, progression blockers, data-loss
issues, and anything that makes the onboarding or an Adventure unclear by
messaging the release organizer directly.
